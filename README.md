# Duel Dash 2P Arcade

Оригинальный Android-проект мини-игр для **одного или двух телефонов**. Проект не использует сторонние игровые движки и тяжёлые библиотеки: интерфейс, мультяшная графика, анимации и мини-игры рисуются Android Canvas.

## Что добавлено в версии 0.2.0

- Красочное аркадное меню с карточками игр.
- Выбор одного из 6 бойцов: Рэй, Фокс, Нова, Турбо, Кики, Фрост.
- Мультяшная отрисовка персонажей: лицо, волосы, одежда, перчатки, обувь, тени.
- Анимации бега, движения конечностей, удара и визуальный эффект попадания.
- Звуковые эффекты: отсчёт, нажатия, удары, очки, победа.
- **Режим без второго телефона**: «Играть сейчас против бота».
- Игра на двух Android-телефонах по Wi‑Fi / точке доступа или Bluetooth Classic.
- Хост остаётся авторитетным устройством для расчёта игрового состояния.

## 7 мини-игр

1. **Драка** — движение, удары, здоровье, отбрасывание.
2. **Гонка** — чередуйте ЛЕВО / ПРАВО и разгоняйтесь к финишу.
3. **Тап-битва** — кто сделает больше нажатий за 10 секунд.
4. **Понг** — управление ракеткой, матч до 5 очков.
5. **Пенальти** — игроки по очереди бьют и защищают ворота, выбирая один из трёх углов.
6. **Реакция** — дождитесь зелёного сигнала и нажмите первым, фальстарт отдаёт очко сопернику.
7. **Перетягивание** — быстрыми нажатиями перетяните канат на свою сторону.

## Игра без второго телефона

Выберите мини-игру и нажмите **«Играть сейчас против бота»**. Wi‑Fi, Bluetooth и подключение второго устройства не нужны. Такая же кнопка есть в меню подключения, поэтому хост может не ждать второго игрока и сразу начать матч с ботом.

## Игра на двух телефонах по Wi‑Fi

1. Оба телефона подключите к одной Wi‑Fi сети. Можно включить точку доступа на одном из телефонов.
2. На первом телефоне выберите игру → «Игра на двух телефонах» → Wi‑Fi → «Создать комнату».
3. Первый телефон покажет локальный IP и порт `45876`.
4. На втором телефоне выберите любую игру → «Игра на двух телефонах» → Wi‑Fi.
5. Введите IP первого телефона и нажмите «Подключиться к хосту».
6. Режим игры и персонаж хоста передаются автоматически.

## Игра по Bluetooth

1. Сначала выполните обычное сопряжение двух телефонов в настройках Android.
2. На первом телефоне создайте Bluetooth-комнату.
3. На втором выберите первый телефон в списке спаренных устройств.
4. На Android 12+ разрешите приложению доступ к «Устройствам поблизости».

## Сборка APK через GitHub Actions

Проект уже содержит `.github/workflows/android-apk.yml`.

1. Загрузите содержимое проекта в GitHub-репозиторий.
2. Откройте вкладку **Actions**.
3. Выберите **Build Android APK**.
4. Нажмите **Run workflow** или просто сделайте новый commit в `main`.
5. После успешной сборки скачайте artifact `DuelDash2P-debug-apk`.
6. В ZIP будет файл `app-debug.apk`.

Workflow использует JDK 17, Android API 35, Build Tools 35.0.0 и Gradle 8.9.

## Структура

- `MainActivity.java` — красивое меню, выбор бойца, режим с ботом, Wi‑Fi/Bluetooth.
- `game/DuelGameView.java` — вся игровая логика, сеть, анимация и Canvas-графика.
- `game/FighterStyle.java` — внешний вид 6 персонажей.
- `game/SoundFx.java` — лёгкие звуковые эффекты через Android ToneGenerator.
- `net/WifiConnector.java` — TCP-соединение в локальной сети.
- `net/BluetoothConnector.java` — Bluetooth RFCOMM.
- `net/PeerConnection.java` — текстовый протокол обмена сообщениями.

## Примечание по дизайну

Интерфейс сделан как самостоятельный яркий аркадный дизайн: крупные цветные карточки, короткие матчи, простое управление и мультяшные персонажи. Чужие игровые ассеты и графика не копируются.
