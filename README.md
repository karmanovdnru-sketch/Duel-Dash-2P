# Duel Dash 2P

Небольшой Android-прототип в духе локальных мини-игр на двух телефонах. В проекте есть две игры:

- **Драка**: два персонажа двигаются по арене, атакуют друг друга, теряют здоровье и могут начать реванш.
- **Гонка**: два персонажа бегут к финишу. Для ускорения нужно быстро чередовать кнопки «ЛЕВО» и «ПРАВО».

Связь между телефонами работает без облачного сервера:

- **Wi-Fi / точка доступа**: один телефон открывает TCP-комнату на порту `45876`, второй подключается к локальному IPv4-адресу хоста.
- **Bluetooth Classic / RFCOMM**: один телефон ждёт соединение, второй подключается к нему из списка уже спаренных Android-устройств.

Хост является авторитетным устройством: он рассчитывает физику, здоровье, победителя и прогресс гонки, а клиент отправляет только управление и получает снимки состояния. Это уменьшает рассинхронизацию.

## Быстрый запуск через GitHub -> APK

1. Создайте пустой репозиторий на GitHub.
2. Распакуйте содержимое архива **в корень репозитория** и загрузите файлы.
3. Откройте вкладку **Actions** и workflow **Build Android APK**.
4. Если workflow не стартовал автоматически, нажмите **Run workflow**.
5. После успешной сборки откройте запуск workflow и скачайте artifact **DuelDash2P-debug-apk**.
6. Внутри artifact будет `app-debug.apk`. Это debug APK, подписанный стандартным debug-ключом Android и пригодный для установки на тестовые телефоны.

Workflow ставит JDK 17, Android SDK API 35, Gradle 8.9 и собирает `:app:assembleDebug`.

## Сборка в Android Studio

1. Установите Android Studio и Android SDK Platform 35.
2. Откройте папку `DuelDash2P` как проект.
3. Дождитесь Gradle Sync.
4. Выберите физический Android-телефон и нажмите **Run**.

Проект использует:

- Java 17
- Android Gradle Plugin 8.7.0
- Gradle 8.9
- `compileSdk = 35`
- `targetSdk = 35`
- `minSdk = 26`

В архив намеренно не добавлен бинарный `gradle-wrapper.jar`: GitHub Actions устанавливает нужную версию Gradle через официальный action. Android Studio также умеет синхронизировать проект по указанной конфигурации.

## Как играть по Wi-Fi

1. Установите приложение на оба телефона.
2. Подключите оба телефона к одной Wi-Fi-сети. Альтернатива: один телефон включает точку доступа, второй подключается к ней.
3. На телефоне 1 выберите **Драка** или **Гонка** -> **Wi-Fi** -> **Создать комнату**.
4. На экране появится локальный IP, например `192.168.43.1`.
5. На телефоне 2 откройте любую игру -> **Wi-Fi**, введите IP телефона 1 и нажмите **Подключиться к хосту**.
6. Реальный режим игры задаёт хост и автоматически передаёт его клиенту.

Если соединение не устанавливается, проверьте, что устройства действительно видят друг друга в локальной сети и что точка доступа не использует изоляцию клиентов.

## Как играть по Bluetooth

1. В системных настройках Android заранее выполните сопряжение двух телефонов.
2. Запустите Duel Dash 2P на обоих устройствах и разрешите доступ к «Устройствам поблизости», если Android спросит.
3. На телефоне 1 выберите игру -> **Bluetooth** -> **Создать Bluetooth-комнату**.
4. На телефоне 2 выберите **Bluetooth** и нажмите имя телефона 1 в списке спаренных устройств.
5. После установки RFCOMM-соединения игра стартует автоматически.

Приложение не выполняет собственное Bluetooth-сканирование, поэтому сопряжение сделано через стандартные настройки Android. Это упрощает разрешения и делает прототип стабильнее.

## Управление

### Драка

- **◀ / ▶**: движение.
- **УДАР**: атака.
- Удар наносит урон только на близкой дистанции.
- После победы нажмите на верхнюю панель результата, чтобы начать реванш.

### Гонка

- Нажимайте **ЛЕВО / ПРАВО / ЛЕВО / ПРАВО** по очереди.
- Правильное чередование даёт более сильное ускорение, повтор одной и той же кнопки даёт слабый толчок.
- Первый персонаж, достигший финиша, побеждает.

## Архитектура

```text
app/src/main/java/com/openai/dueldash/
├── MainActivity.java              # меню, выбор транспорта, соединение
├── game/
│   ├── DuelGameView.java          # Canvas-рендер, физика, управление, протокол
│   ├── GameMode.java
│   └── PlayerInput.java
└── net/
    ├── PeerConnection.java        # построчный двусторонний канал
    ├── WifiConnector.java         # TCP host/client
    ├── BluetoothConnector.java    # RFCOMM host/client
    └── ConnectionAttempt.java
```

Текстовый сетевой протокол специально простой:

- `MODE|FIGHT` / `MODE|RACE` - режим хоста.
- `I|0|1|1` - управление клиента в драке: left/right/attack.
- `T|L` / `T|R` - отдельное нажатие в гонке.
- `S|...` - снимок авторитетного состояния от хоста.
- `RESTART` - запрос реванша.
